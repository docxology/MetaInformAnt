# analysis (METAINFORMANT information module)

Subpackage of `metainformant.information`.

## Modules

- `advanced_analysis.py` — Advanced information-theoretic measures for biological data.
- `analysis.py` — High-level information analysis functions for biological sequences.

Run tests for this area with `pytest tests/information/ -v` from the repo root. Outputs belong in `output/`, temp files in `.tmp/`.
