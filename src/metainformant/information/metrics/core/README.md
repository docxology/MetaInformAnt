# core (METAINFORMANT information module)

Subpackage of `metainformant.information`.

## Modules

- `continuous.py` — Continuous information theory measures for numerical data.
- `estimation.py` — Bias-corrected entropy and information estimation methods.
- `syntactic.py` — Syntactic information theory measures for biological sequences.

Run tests for this area with `pytest tests/information/ -v` from the repo root. Outputs belong in `output/`, temp files in `.tmp/`.
