# statistical (METAINFORMANT gwas module)

Subpackage of `metainformant.gwas`.

## Modules

- `comparison.py` — GWAS comparison visualization utilities.
- `effects.py` — GWAS effect size visualization utilities.
- `statistical.py` — Statistical visualization functions for GWAS.

Run tests for this area with `pytest tests/gwas/ -v` from the repo root. Outputs belong in `output/`, temp files in `.tmp/`.
