# interactive (METAINFORMANT gwas module)

Subpackage of `metainformant.gwas`.

## Modules

- `composite.py` — Composite multi-panel visualization for GWAS.
- `finemapping.py` — Fine-mapping visualization functions for GWAS.
- `interactive.py` — Interactive visualization functions for GWAS using Plotly.
- `phenotype.py` — Phenotype visualization for GWAS.
- `suite.py` — Comprehensive GWAS visualization suite.

Run tests for this area with `pytest tests/gwas/ -v` from the repo root. Outputs belong in `output/`, temp files in `.tmp/`.
