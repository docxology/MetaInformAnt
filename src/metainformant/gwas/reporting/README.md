# reporting (METAINFORMANT gwas module)

Subpackage of `metainformant.gwas`.

## Modules

- `audit.py` — GWAS pipeline audit and provenance utilities.
- `html_report.py` — Self-contained HTML report generator for GWAS post-analysis.

Run tests for this area with `pytest tests/gwas/ -v` from the repo root. Outputs belong in `output/`, temp files in `.tmp/`.
