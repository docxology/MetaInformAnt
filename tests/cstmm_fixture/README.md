# cstmm_fixture tests

Shared test fixture tree for the CSTMM cross-species expression-merge pipeline (`cstmm`/`csca` steps of the hymenoptera_amalgkit workflow).


Subdirectories: `csca`, `cstmm`, `curate`, `merge`, `metadata`, `orthogroups`.

Run from the repo root: `pytest tests/cstmm_fixture/ -v`. Tests follow the real-implementation policy (no mocks).
