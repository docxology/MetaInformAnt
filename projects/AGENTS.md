# Project guidance

Read [root guidance](../AGENTS.md), then the nearest project `AGENTS.md` before editing.
See [`README.md`](README.md) for included public templates (`template_bioinformatics_project/`) versus optional private extension checkouts (`projects/hymenoptera_amalgkit`, `projects/apis_gwas`).
Optional private repositories are never declared in `.gitmodules` in the public repository so `git clone --recursive` succeeds without credentials.
Keep raw datasets and runtime products in each documented external/output root.
Project documentation must distinguish processing progress from validated results.
