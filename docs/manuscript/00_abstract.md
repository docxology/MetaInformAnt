# Abstract

MetaInformAnt is a public research software package with shared infrastructure for reading, writing, and validating scientific records [@metainformant]. This software-methods study examines delimiters, explicit type conversion, schema constraints, and durable local evidence. A deterministic scale benchmark writes and rereads synthetically generated count tables, checks the values against an independent formula, and exercises malformed counterparts. Accepted cases preserve the expected row order, counts, and totals. The expected failures isolate schema, lexical, range, and identity requirements. A machine-readable receipt records per-case verdicts and artifact digests. The study establishes behavior of the selected public interfaces on these fixtures, with scope limited to offline table and metadata handling.
