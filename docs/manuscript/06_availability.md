# Availability and reproducibility

The source, experiment, and rendering instructions accompany the public MetaInformAnt repository [@metainformant]. The data for this paper are invented by the experiment. Running the exporter regenerates the TSV inputs, the results receipt, and the figure. Each case records a content hash of the corresponding TSV. Template validation additionally binds the rendered artifacts to their exported manuscript sources.

This study is a fresh offline software verification. Its citation records identify the software and tabular-data model, and its rendered outputs describe only the scoped implementation and experiment.
