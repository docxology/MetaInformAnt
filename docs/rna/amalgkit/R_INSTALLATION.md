# Optional R environment

The current MetaInformAnt workflow executes Amalgkit acquisition,
quantification, merge, filtering, finalization, and sanity commands through
the installed CLI. R is not required for those gates.

Install R only when a declared downstream analysis uses an R package such as
DESeq2, edgeR, limma, or a project-specific visualization. Record the R
version, package versions, and session information in the analysis manifest.

## Verify

```bash
R --version
Rscript -e 'sessionInfo()'
```

## Reproducibility rule

Do not add an R dependency to the core Amalgkit workflow merely to produce a
plot. Figures must be generated by the documented analysis script from the
validated final tables. If an R-based statistical model is used, its input
table, design formula, contrasts, filtering rule, package versions, and
multiple-testing procedure belong in the manuscript methods and evidence
manifest.
